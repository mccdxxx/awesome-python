## Admin Panels

_Libraries for administrative interfaces._

- [ajenti](https://mccdxxx.github.io) - The admin panel your servers deserve.

- [flask-admin](https://mccdxxx.github.io) - Simple and extensible administrative interface framework for Flask.
- [flower](https://mccdxxx.github.io) - Real-time monitor and web admin for Celery.

- [wooey](https://mccdxxx.github.io) - A Django app which creates automatic web UIs for Python scripts.

## ASGI Servers
